# 📊 Retail Store KPI Dashboard — Power BI

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze retail store sales performance, profitability, orders, and product categories.

## 🎯 Key Performance Indicators (KPIs)
- Total Sales Revenue
- Total Profit
- Total Orders
- Total Quantity Sold
- Profit Margin (%)

## 📈 Dashboard Features
- Sales Analysis by Region
- Sales Analysis by Product Category
- Sales Trends Over Time
- Interactive Date Filter
- Region Filter
- Category Filter

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel

## 📂 Project Files
- `Retail_Store_KPI_Dashboard.pbix` — Power BI dashboard file.

## 📊 Key Insights
The dashboard helps users explore sales performance, compare regions, identify category trends, and monitor profitability using interactive filters.
